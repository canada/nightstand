# Nightstand

iPhone の StandBy 風に、アナログ時計・カレンダー（日本の祝日対応）・天気を表示する静的ページ。ビルドや追加ライブラリは不要。

- 公開ページ: https://canada.github.io/nightstand/
- iPhone: Safari で開く → 共有 → ホーム画面に追加（Web アプリとして開く）
- 祝日: 内閣府 `syukujitsu.csv`（取得できない場合は holidays-jp API）
- 天気: Open-Meteo（位置情報、または `?lat=35.68&lon=139.76` で固定）
- 操作: 右上を1回タップでボタン表示 → もう1回タップでモード切替（自動 / ナイト / デイ）。左右スワイプで月移動

## 改良版を試す

- [改良版](https://canada.github.io/nightstand/?next=1)
- [クラシック](https://canada.github.io/nightstand/)
- [確認用サイト](https://nightstand-preview.canadie.chatgpt.site/?next=1)（本人のみアクセス可能）

通常のURLではクラシックを表示し、`?next=1` を付けると追加機能を読み込む。固定位置との併用は `?next=1&lat=35.68&lon=139.76`。GitHub Pagesは `main` ブランチのルートを配信する。

- カレンダー上の上下スワイプ、縦ドラッグ、マウスホイール、上下キーで前月・翌月へ移動する。年月と曜日は同じ位置に固定し、日付だけが指について縦に動く。短いドラッグは元の月に戻る。前月末・翌月初めの日付は控えめな色で並べ、月をまたぐ週を途切れさせない。年月横の戻る矢印で当月に戻る。左右キーも利用できる。
- カレンダーの日付は大きめに表示し、日曜・祝日は淡い赤、土曜は淡い青で区別する。ナイトモードでは赤系の配色を保つ。
- 普段の天気表示はアイコン・気温・天気の説明・最高／最低気温を表示し、押すと現在の詳細、今後12時間、7日間の予報を表示。詳細は開いたときに取得し、15分間キャッシュする。取得できない場合は前回の予報であることを表示し、再取得できる。
- 時計を押すとタイマーを表示。1・3・5・10・15・30分のプリセット、任意の分・秒の設定、停止・再開・キャンセルに対応。時計内には小さな残り時間の数字だけを表示し、終了後の `00:00` は30秒後に消える。終了・一時停止などの説明は時計を押して開くタイマー画面に表示する。
- タイマーは端末内に保存し、再読み込み後も締切から残り時間を復元する。通知音はページが動作中の場合に鳴る。端末のロックやブラウザ停止中の音・通知は保証しない。復帰すると経過時間を反映する。

## コードの分離

`index.html` は既存のマークアップとクエリによる読み込みだけを持つ。`classic.css` と `classic.js` は元のスタイルと処理をそのまま切り出したもの。`classic.js` の小さな `NightstandClassic` インターフェースを通じて、月移動・天気のアイコンや表示・位置情報取得を再利用する。

追加機能は `enhancements.js` / `enhancements.css`、天気詳細は `weather-detail.js` / `weather-detail.css`、タイマーは `timer.js` / `timer.css` に置く。クエリのないクラシックでは、これらを読み込まない。追加機能に対してもクラシックの昼夜の配色を使う。

予定表のTeams連携は未実装。後続では、認証・予定データを接続したブラウザに限定し、公開ファイルや他端末へ共有しない構成を検討する。
